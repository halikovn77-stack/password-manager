# 🔐 Password Manager

Консольный менеджер паролей с шифрованием базы данных SQLite.

## ✨ Возможности

- 🔒 **Полное шифрование** — вся база данных хранится в зашифрованном виде (Fernet)
- 🔑 **Мастер-пароль** — доступ только по одному главному паролю (PBKDF2 + соль)
- 📝 **Управление паролями** — добавление, поиск, обновление, удаление
- 👥 **Несколько аккаунтов** — для одного сервиса можно хранить несколько логинов
- 🎲 **Генератор паролей** — создание надёжных случайных паролей
- 📋 **Логирование** — все действия записываются в файл
- 🛡️ **Защита от случайного удаления** — двойное подтверждение

## 🚀 Быстрый старт

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/your-username/password-manager.git
cd password-manager

# Устанавливаем зависимости
pip install cryptography
```

### Запуск

```bash
python password_manager.py
```

### Первый запуск

При первом запуске программа попросит **придумать мастер-пароль**:

```text
ПЕРВЫЙ ЗАПУСК! Создаю новый мастер-пароль.

Придумайте мастер-пароль: 
Повторите мастер-пароль: 

Соль сохранена. ЗАПОМНИТЕ МАСТЕР-ПАРОЛЬ! Без него данные не восстановить.
```

⚠️ ВАЖНО! Мастер-пароль не хранится нигде. Если вы его забудете — доступ к паролям будет потерян навсегда!

## 📖 Использование

После запуска появится главное меню:

```text
==================================================
           МЕНЕДЖЕР ПАРОЛЕЙ
==================================================
  1. 🔐 ДОБАВИТЬ пароль
  2. 🔍 НАЙТИ пароль
  3. 📋 СПИСОК сервисов
  4. 🔄 ОБНОВИТЬ пароль
  5. 🗑️  УДАЛИТЬ пароль
  6. 🎲 СГЕНЕРИРОВАТЬ пароль
  7. 🚪 ВЫЙТИ
==================================================
```

### Добавление пароля

- Введите название сервиса, логин и пароль
- Программа проверит, нет ли уже такого аккаунта

### Поиск пароля

- Введите название сервиса
- Программа покажет ВСЕ аккаунты для этого сервиса

### Генерация пароля

- Выберите длину (по умолчанию 16)
- Выберите тип символов:
  - Только буквы
  - Буквы + цифры
  - Буквы + цифры + спецсимволы (рекомендуется)
  - Только цифры
- Программа покажет сгенерированный пароль и предложит сохранить его

## 📁 Структура проекта

| Файл | Назначение | Статус |
| :--- | :--- | :--- |
| `password_manager.py` | Основной код программы | Исполняемый |
| `salt.bin` | Соль для создания ключа (не секретная) | Служебный |
| `passwords.enc` | Зашифрованная база данных | **Секретно** |
| `password_manager.log` | Лог всех действий | Служебный |
| `passwords.db` | Временная БД (создается и удаляется) | Временный |

## 🛡️ Безопасность
- Мастер-пароль никогда не сохраняется на диске
- Ключ шифрования создаётся заново при каждом запуске из пароля и соли
- PBKDF2 с 100 000 итераций защищает от подбора пароля
- Все действия логируются, но пароли в лог не попадают
